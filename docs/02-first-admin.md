# ساخت اولین مدیر

هیچ رمز عبور ثابتی در کد یا مخزن وجود ندارد. اولین مدیر (نقش «owner») فقط با اسکریپت زیر
ساخته می‌شود:

```bash
docker compose exec app npm run create-first-admin
```

رفتار:

- اگر `FIRST_ADMIN_EMAIL` در `.env` تنظیم نشده باشد، اسکریپت با خطا متوقف می‌شود.
- اگر `FIRST_ADMIN_PASSWORD` تنظیم نشده باشد، یک رمز تصادفی امن (کاملاً محلی، بدون اتصال
  خارجی) ساخته و **فقط همان یک‌بار** در ترمینال چاپ می‌شود. آن را در یک مدیر رمز عبور ذخیره
  کنید.
- اگر مدیری با نقش owner از قبل وجود داشته باشد، اسکریپت هیچ کاری انجام نمی‌دهد (برای
  جلوگیری از ساخت تصادفی مدیر تکراری).

پس از اولین ورود به `/admin`، پیشنهاد می‌شود رمز عبور را از تنظیمات حساب کاربری در پنل تغییر
دهید.

برای ساخت مدیران بعدی (مدیر کسب‌وکار، پشتیبان)، از داخل پنل توسط یک owner انجام می‌شود
(بخش «تنظیمات → حساب‌های مدیر»)، نه از این اسکریپت.
